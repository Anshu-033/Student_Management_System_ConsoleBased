# Student Management System 🎓

A console-based Student Management System developed using **Java**. This project was created to practice Java programming concepts and build a simple application for managing student information through the command line.

## ✨ Features

* Add student details
* View student information
* Manage student records through the console
* Simple menu-driven interface
* Easy-to-use command-line interaction

## 🛠️ Technologies Used

* **Java**
* **Java Collections Framework**
* **JDBC (Java Database Connectivity)**
* **SQL**
* **MySQL**


## ▶️ How to Run

1. Clone the repository.
2. Open the project in a Java-supported IDE or terminal.
3. Compile the Java files.
4. Run the main Java class.
5. Follow the instructions displayed in the console.
